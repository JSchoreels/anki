# The family wiring (SM114): every size runs the RWKV family release — 2026-11-13

The user's decision of 2026-11-13: the fork runs exactly the models of the published RWKV family release (anki-rwkv release `rwkv-family-2026-11-13`), and a size never falls back to another size's model. If the profile picks Tiny, only Tiny models run; Small only Small models; Big only Big models. Whether a pair or one model runs is still chosen by the existing options (the schedulers the presets use and **Use one model for RWKV**), never by a choice across sizes. This reverses two rules of the earlier wiring: RWKV-Curve of Small and Tiny no longer comes from the default small model (SM63), and RWKV-Instant alone in Small no longer runs the Tiny Instant-Only model (SM101) (the "Tiny when instant-only" rule of 2026-11-12, see the [SM112 report](rwkv-sm112-2026-11-13.MD)).

## What each size runs

Presets "use RWKV-Curve" when RWKV-Curve is their scheduler or RWKV-Instant's **Fallback : Due-Date Calculator** (both set `rwkv_review_enabled`). Changes against the previous build in bold.

| Presets use | Big (`legacy`) | Small (`sm72e25`, default) | Tiny (`tiny`) |
| --- | --- | --- | --- |
| RWKV-Instant and RWKV-Curve (default) | the show-time big model (SM91s2) beside the show-time instant-only big model (SM99) | **the show-time retrain (SM92)** beside the Small Instant-Only model (SM98) (was the default small model (SM63) + SM98) | **the Tiny two-head model (SM106)** beside the Tiny Instant-Only model (SM101) (was SM63 + SM101) |
| both, with the one-model opt-out | the show-time big model (SM91s2) alone | the show-time retrain (SM92) alone | the Tiny two-head model (SM106) alone |
| RWKV-Instant without RWKV-Curve (opt-out ignored) | the show-time instant-only big model (SM99) alone | **the Small Instant-Only model (SM98) alone** (was the Tiny Instant-Only model (SM101)) | the Tiny Instant-Only model (SM101) alone |
| RWKV-Curve only, or neither | the show-time big model (SM91s2) alone | **the show-time retrain (SM92) alone** (was SM63) | **the Tiny two-head model (SM106) alone** (was SM63) |

Code: `qt/aqt/rwkv_model.py` now holds one table, `RWKV_SIZE_MODELS`, mapping each size to its `RwkvSizeModels(two_head, instant)`, and `runtime_models()` picks only from it: the pair for both schedulers, the two-head model alone with the opt-out or without RWKV-Instant, the Instant-Only model alone without RWKV-Curve. The size-crossing constants and their comments are removed: `RWKV_INSTANT_ALONE_MODEL` (SM101 for Small), `RWKV_CHOICE_INSTANT_ALONE_MODELS`, `RWKV_CHOICE_CURVE_MODELS` (Tiny's curve from SM63), `RWKV_CHOICE_INSTANT_MODELS`, `RWKV_CHOICE_SINGLE_MODELS` and `RWKV_INSTANT_MODEL_RELEASES`; the model constants are named by size and role (`RWKV_SMALL_TWO_HEAD_MODEL` = `sm92`, `RWKV_SMALL_INSTANT_MODEL` = `sm98`, `RWKV_TINY_TWO_HEAD_MODEL` = `sm106`, `RWKV_TINY_INSTANT_MODEL` = `sm101`, `RWKV_BIG_INSTANT_MODEL` = `sm99`). No Rust runtime change was needed: the native paired runtime already accepted any two distinct small models with the same leak-free input rule.

**The default small model (SM63).** No size runs it any more. Its weights stay bundled (`qt/aqt/rwkv_inference/sm72e25/`, model kind `sm72e25`, with its answer-time head), and it stays selectable as an explicit profile value: `rwkvModel` = `sm63` (`RWKV_MODEL_SM63`, resolved to the model key `sm72e25` by `RWKV_CHOICE_MODEL_ALIASES`) runs it alone for both schedulers, like the older small models: Deck Options shows it as Small, and the next Deck Options save stores Small (`RWKV_OLDER_SMALL_MODELS` in `ts/routes/deck-options/lib.ts`). The profile value `sm72e25` keeps meaning Small, so existing profiles keep their size. The preserved choice of the show-time retrain (SM92) and the older small keys still run their one model alone in every case.

**Custom checkpoints.** `ANKI_RWKV_MODEL_PATH` replaces the size's two-head model (`curve_model_for_choice`), so under Tiny the checkpoint is loaded with the Tiny two-head model (SM106)'s key and must have one card layer (the runtime refuses other weights); under Small it is loaded with the show-time retrain (SM92)'s key.

## Accuracy and memory

Show-time inputs, 722 users of the 732-user held-out set, w8+s8, review-weighted LogLoss (lower is better), from the family release notes and the Model Factory table:

| Two-head model | Curve LogLoss | vs the show-time big model (SM91s2) (0.299415) |
| --- | --- | --- |
| the default small model (SM63), Small's and Tiny's curve until now | 0.300414 | +0.33% |
| the show-time retrain (SM92), Small's curve now | 0.300356 | +0.31% |
| the Tiny two-head model (SM106), Tiny's curve now | 0.300676 | +0.42% (+0.11% vs SM92) |

The Instant-Only models are unchanged by this task: Big 0.275894, Small 0.276191, Tiny 0.27672. In Small's RWKV-Instant-alone mode the Small Instant-Only model (SM98) replaces the Tiny Instant-Only model (SM101): Instant LogLoss 0.19% lower, 3,530 B instead of 2,622 B per card and note.

Stored state per card and note at the default precision (int4 cards + int8 notes), checked by `rwkv_family_pairs_match_each_model_alone` for the pairs:

| Size | RWKV-Instant alone | Two-head alone | Pair (both schedulers) |
| --- | --- | --- | --- |
| Big | 19,554 B | 19,554 B | 39,146 B |
| Small | **3,530 B** (was 2,622 B) | 3,530 B | 7,098 B |
| Tiny | 2,622 B | 2,622 B | **5,282 B** (was 6,190 B) |

Deck Options' size descriptions say this: Small about 3.5 KB with Instant only (82% less than Big) or 7.1 KB with both (82% less), Curve 0.31% / Instant 0.11% higher than Big; Tiny about 2.6 KB or 5.3 KB (26% less than Small, 87% less than Big), Curve 0.42% / Instant 0.30% higher than Big (0.11% and 0.19% higher than Small), and no answer-time estimate. The one-model explanation says the opt-out uses the size's Curve model for both, and the Instant-only line that the size's Instant model runs alone.

## Answer-time estimate

The main (two-head) model keeps the answer-time head. The show-time retrain (SM92) has one in the fork (`qt/aqt/rwkv_inference/sm92/time_head.*`), so Small keeps its answer-time estimate in every mode with a curve; the family release itself does not ship that head. The Tiny two-head model (SM106) and the show-time big model (SM91s2) have none, so Tiny now shows no RWKV answer-time rows in its pair and curve-only modes, as it already did with the one-model choice. Nothing new is needed for that: Card Info asks the backend `has_answer_time_head()`, and the paired runtime answers it from its two-head model (tested natively for both family pairs: SM92 + SM98 has the head, SM106 + SM101 does not, exactly like each two-head model alone). An instant-only runtime never shows those rows.

## State: one rebuild per changed combination

The replay key holds `model` and, for a pair, `instantModel`; the model cache key holds the weights' SHA-256. Eight of the 18 size × scheduler × opt-out combinations change models and so rebuild their state once from the review history, then reuse it:

| Size | Combination | Before (SM112) | Now |
| --- | --- | --- | --- |
| Small | RWKV-Instant alone (with or without the opt-out) | the Tiny Instant-Only model (SM101) | the Small Instant-Only model (SM98) |
| Small | both | the default small model (SM63) + SM98 | the show-time retrain (SM92) + SM98 |
| Small | RWKV-Curve only, neither | SM63 | SM92 |
| Tiny | both | SM63 + SM101 | the Tiny two-head model (SM106) + SM101 |
| Tiny | RWKV-Curve only, neither | SM63 | SM106 |

The other ten keep their state: all six of Big, Small's and Tiny's opt-out with both schedulers (SM92 and SM106 alone, as before) and Tiny's RWKV-Instant alone (SM101, as before). Within a size, RWKV-Curve only, neither and the opt-out with both now run the same two-head model alone and share one state; switching between sizes always rebuilds, since no two sizes share a model.

## Tests

- **Python, the 18-combination test** (`qt/tests/test_rwkv_model.py`): every size × use case maps to exactly the table above (`_SIZE_RUNTIMES` against `FAMILY`, the family release's pairs); no size ever loads another size's weights, checked on the model keys (`RWKV_MODEL_FILES`) and on the paths the native backend is created with for every size × preset layout; two combinations share a replay key exactly when they run the same models, never across sizes; the new `test_family_wiring_rebuilds_each_changed_combination_once` compares every combination with the SM112 mapping and asserts that exactly the eight combinations above get a new replay key; `test_states_built_on_the_previous_model_rebuild_once` checks the refused old cache and the reused new one for Small's RWKV-Instant alone, both and curve-only and Tiny's both, curve-only and opt-out; each size's Instant-Only model alone reopens into the size's own pair or two-head model once a preset turns RWKV-Curve on; SM63 stays bundled, is reachable only as `sm63` and is never picked by a size.
- **Rust** (`rslib/src/rwkv/runtime.rs`): new `rwkv_family_pairs_match_each_model_alone`: the show-time retrain (SM92) + the Small Instant-Only model (SM98) and the Tiny two-head model (SM106) + the Tiny Instant-Only model (SM101) load as pairs at f32, int8 and int4 cards + int8 notes; instant recall and buttons equal the Instant-Only model alone and the curve recall, intervals, S90 and answer times the two-head model alone, bit for bit, through warm-up, queries, explicit-state reviews, post-answer replay and future-recall snapshots; answer-time head only with SM92; stored pair state 7,098 B and 5,282 B per card and note. `rwkv_switching_sizes_never_reuses_another_layout_state` now holds the family's Small and Tiny layouts (pair, two-head alone, Instant-Only alone). The manual model-size benchmark lists the family runtimes plus SM63 alone.
- **Native bridge** (`qt/tests/test_rwkv_inference_process.py`, against a freshly built release `rsbridge`): the two family pairs are readable and prunable at all three precisions, and the new `test_rsbridge_rwkv_family_pair_serves_instant_and_two_head_keeps_curve` checks, at all three precisions, that the pair's instant outputs equal the Instant-Only model alone and its curve recall, current interval, S90, intervals and S90s the two-head model alone after a replayed history, with the answer-time head of the two-head model.
