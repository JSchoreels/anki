# SM56 integration — 2026-10-24

SM56 replaces SM55 as the default small model. Deck Options → RWKV → Advanced → **Use Smaller Model** selects SM56 when on and Legacy when off. New profiles and profiles without a supported saved choice default to SM56. Existing explicit selections continue to load; a successful ordinary Deck Options save upgrades SM40, SM36 or SM55 to SM56. Discard, a failed save and parameter-only optimization preserve the saved selection. Reopen the profile to apply a saved change. Storage precision and f32 computation are unchanged; zstd remains disabled.

## Runtime, settings and verification

All five profile values (`legacy`, `sm40`, `sm36`, `sm55`, `sm56`) remain supported at runtime. Four small checkpoints share one native specialization; Legacy uses the other. Model enum variants are appended, preserving earlier discriminants. Model selection and weight-content identity invalidate incompatible caches and undo snapshots; no state schema migration is required. The active session and background work retain their model and precision until profile reopen. Switching reconstructs state from retained review history without rewriting scheduling dates or collection data.

The desktop bundles SM56's f32 weights, architecture and manifest. The optional INT8 container is retained for reference tests, not selected for production computation. The built runtime assets are checked against source package hashes. Default storage remains INT4 card matrices / INT8 note matrices, with f32 row scales/shared state and f16 shifts. Saved precision values are preserved.

SM56 supports both Instant and Curve under all four storage policies, in RAM and in checkpoints:

| Profile value | Card matrices | Note matrices |
| --- | --- | --- |
| `f32` | f32 | f32 |
| `int8` | INT8 | INT8 |
| `int4` | INT4 | INT4 |
| `cards_int4_notes_int8` (default) | INT4 | INT8 |

Weights, computation and shared scopes remain f32 in every policy. Quantized modes use f16 shifts and f32 row scales. This is state quantization, not integer-only INT4/INT8 weight computation. Native restore and desktop checkpoint, answer/undo and workload tests include SM56 under every policy. Upstream many-user quality evidence covers its w8+s8 setup, not separate accuracy measurements for all four desktop policies.
