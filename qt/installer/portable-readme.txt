ANKI PORTABLE FOR MACOS
=======================

Keep this entire "Anki Portable" folder together. Open Anki Portable.app to
start Anki. The app creates and uses only the adjacent "Anki Portable Data"
folder for its preferences, profiles, collections, media, add-ons, backups,
logs, and temporary files.

You can move the complete folder after quitting Anki. Moving only the app will
start it with a new data folder beside its new location.

The normal installed Anki and this portable copy can run at the same time. They
do not share local data. If both copies sign in to the same AnkiWeb account,
they can still exchange collection changes through sync.

Application update checks are disabled in the portable edition because the
standard macOS updater installs the normal edition. Replace the portable app
with a newer portable build to update it, while keeping the data folder.

This portable edition separates Anki's application data; it is not an operating
system security sandbox. Add-ons retain the permissions of your macOS account.
